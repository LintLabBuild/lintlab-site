## The idea

Writing code that works is taught everywhere. Writing code that is safe almost
nowhere. SecureCode tests the second skill: an assessment where the question is not
only "does it pass?" but "can it be broken?".

## How it works

- Students solve problems inside a **locked-down exam environment**.
- Each submission is reviewed for common vulnerability classes such as injection,
  broken access control and unsafe input handling.
- The review **explains the fix** in plain words and gives the examiner a grading aid.
  The examiner makes the final call.

## Background

The idea started as our Smart India Hackathon 2026 entry and shares its judge and
sandbox with the [Lint Contest Platform](/work/lint-contest-platform/).
